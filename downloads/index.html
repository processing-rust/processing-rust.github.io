Two ways to get Rust Mode, depending on how you want to work.

Installing Rust Mode

Rust Mode isn't in the Contribution Manager yet, so it's installed by hand. You also need Rust itself: get it from rustup.rs if you don't have it.

  1. Download the Rust Mode zip from the latest release.
  2. Unzip it into the modes folder of your sketchbook (Processing shows where the sketchbook is in File > Preferences), so you have sketchbook/modes/RustMode.
  3. Restart Processing and pick Rust from the mode dropdown in the top-right of the editor.

The zip comes with the engine already compiled for some computers, so your first Run is quick there. On the others the first Run builds the engine once, which takes a few minutes.

The engine as a crate

For writing plain Rust in your own editor, with no Processing IDE involved. The quickest start is the starter project: unzip it and cargo run.

Download the starter project Download the crate

To add the engine to a project you already have, put this in its Cargo.toml. The [patch] part points Bevy at the Processing fork the engine is built on. Cargo only reads it from your own top-level Cargo.toml, so it has to be there too:

[dependencies]
processing = { git = "https://github.com/llamasjc/processing-rust" }

[patch."https://github.com/bevyengine/bevy"]
bevy = { git = "https://github.com/processing/bevy", branch = "main" }

and give it your sketch:

use processing::*;

struct Sketch { x: f32 }

fn setup(s: &mut Sketch) {
    size(640, 360);
}

fn draw(s: &mut Sketch) {
    background(20);
    s.x = (s.x + 2.0) % width();
    ellipse(s.x, height() / 2.0, 40.0, 40.0);
}

fn main() {
    App::new(Sketch { x: 0.0 }, setup, draw).run();
}

Then cargo run. The code and every release are on GitHub.
