What's New

Rust Mode keeps Processing's shape. A sketch is still setup(), draw() and the calls you know. What changes is that it's Rust, so types are strict and names use snake_case: noStroke() is no_stroke() and mouseX is mouse_x() (the camelCase names work too). These are the things to know.

Changed
Sketch variables are let at the top

Variables your sketch keeps between frames are let lines at the top of the file. Add mut when they change. Rust Mode makes them available in setup(), draw() and the event functions.

let mut x: f32 = 0.0;

fn draw() {
    background(0);
    x += 1.0;
    ellipse(x, 50.0, 20.0, 20.0);
}
Changed
Numbers have one type

Rust doesn't mix i32 and f32 on its own. Write 2.0 when the number is an f32, and convert with as: i as f32, x as i32. Processing's calls take whole numbers fine: size(640, 360), fill(255, 0, 0).

Changed
Math is a method

sin(a) becomes a.sin(), sqrt(x) can be x.sqrt(), and atan2(y, x) is y.atan2(x). map(), dist(), lerp(), constrain() and random() are the same as in Java.

Changed
Classes are structs

A class becomes a struct with its fields, and an impl with new() and its methods. A method that changes the object takes &mut self.

struct Ball { x: f32, y: f32 }

impl Ball {
    fn new(x: f32, y: f32) -> Ball {
        Ball { x, y }
    }
    fn display(&self) {
        ellipse(self.x, self.y, 20.0, 20.0);
    }
}

Rust has no extends. A struct can hold the one it builds on as a field, and a trait lets different kinds share one list.

Changed
Lists are Vec

Java's arrays and ArrayList are both Vec: vec![0.0; 10], list.push(v), list.len(), for b in balls.iter_mut() { ... }.

Changed
Text uses format!

Join text with format!: text(&format!("score: {}", score), 10.0, 20.0). Functions that take text take &str.

Changed
Images and layers are ids

load_image() and create_graphics() give you a u64 id. Ask it for what you need: img.width(), img.get(x, y). Draw into a layer between begin_graphics(pg) and end_graphics().

Pixels are a copy: let mut px = load_pixels();, change it, then update_pixels(&px);.

Same
Overloads by number of arguments

fill(255), fill(255, 0, 0) and fill(255, 0, 0, 128) all work. Rust Mode picks the right engine function for you (fill_rgb, fill_rgba...).

New
Two renderers

The toolbar has a renderer menu. The default draws on the CPU. libprocessing draws with Bevy and wgpu on your graphics card, with real 3D lights and shaders.
