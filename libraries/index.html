Libraries

Everything available in Rust Mode out of the box.

None of these need a use line. Rust's standard library is always there, and every sketch starts with use processing::*; for you.

Rust's standard library

Vec

Growable list. The one to use instead of Java's arrays and ArrayList.

HashMap / BTreeMap

Key-value maps: std::collections::HashMap. BTreeMap keeps the keys sorted.

HashSet / BTreeSet

Collections of unique values.

VecDeque

A queue you can add to and take from at both ends.

String / &str

Text. format!("x = {}", x) builds strings; text() takes &str.

Iterators

for x in list.iter(), .map(), .filter(), .sum(), .enumerate().

f32 math

angle.sin(), x.sqrt(), y.atan2(x), v.abs(): math is a method on the number.

println! / format!

Print to the console, build text. Processing's println() works too.

Processing's types

PVector

2D and 3D vectors: v.add(&w), v.mag(), v.normalize(), and + - * / between vectors.

Color

A color: color_rgb(255, 0, 0), red(c), lerp_color(a, b, t). Color::from_u32 for pixels.

IntList / FloatList / StringList

Processing's lists, with sort(), shuffle(), sum() and the rest.

IntDict / FloatDict / StringDict

Processing's dictionaries.

Table / TableRow

CSV and TSV files: load_table(), t.get_row_count(), row.get_float("x").

Json / Xml

load_json_object(), json.get_json_array("items"), load_xml(), xml.get_children("item").

Images and layers

Images are ids (u64): img.width(), img.get(x, y), img.load_pixels(). Layers from create_graphics() draw between begin_graphics(pg) and end_graphics().

PShape / fonts / PShader

SVG and OBJ shapes, create_shape(), fonts from create_font(), and GLSL shaders.
