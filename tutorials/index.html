Tutorials

Rust Mode comes in two forms. One is a plugin for the Processing IDE, which lets you write sketches inside Processing itself just like you normally would. The other is the engine as a Rust crate you can use in any Cargo project. Pick the section that matches what you're trying to do.

Using Rust Mode inside the Processing IDE

Write setup() and draw() as Rust functions, hit Run, and see a window open. Rust Mode turns your sketch into a small Rust program and compiles it against a prebuilt engine, so after the first run it only rebuilds your code.

Using the engine in your own Rust project

The engine is a normal crate. Add it to Cargo.toml, write a main() that hands it your state and your setup and draw functions, and build with cargo run. See the crate on the Downloads page.

Still not sure which one fits? If you know Processing and just want to keep working the same way, go with Getting Started. If you already have a Cargo project, use the crate.
